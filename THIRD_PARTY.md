# Third-party sources

`src/markdown.kex` and `src/markdown/inline.kex` adapt the Markdown parser
from `kexhq/kex`, `tey/src/tey/docgen/md.kex`, distributed under the MIT
license. The parser is a documented Markdown subset, not a CommonMark
implementation.

`src/markdown/highlight.kex` adapts the Kex highlighter from the same
directory (`highlight.kex`), MIT.
